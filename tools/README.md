# Tools

Repository tooling is grouped by output:

| Directory | Purpose |
| --- | --- |
| `icons/` | Generate the macOS icon bundles, Windows `.ico`, and icon font from SVG masters |
| `licenses/` | Generate the Debian copyright file and third-party license manifest |

Run scripts from the repository root. Packaging entry points live under
`packaging/`; generated application assets remain in `assets/` and `fonts/`.
